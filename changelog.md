#### GUI, TUI und Weboberfläche / GUI, TUI and Web Interface

- Update-Hinweise zeigen das Changelog sauber formatiert ohne interne Kommentare. Updates werden auf dem Darts-Hub-Rechner heruntergeladen und dort nach Bestätigung installiert; Einstellungen und Installationsordner bleiben erhalten.

- Gespeicherte Änderungen erscheinen automatisch auch in anderen geöffneten Oberflächen derselben Installation. Ungespeicherte Eingaben bleiben erhalten; wartende Aktualisierungen werden angezeigt und anschließend nachgeladen.

- Neue geführte Einführung auf Deutsch und Englisch: Einrichtung, Soundpacks, Ereignisse, HubX und Support mit abgedunkelter Umgebung, animiert hervorgehobenen Bedienelementen, kleinen Mitmachaufgaben mit automatischem Weitergehen, gestalteten Zusatzinfos und gespeichertem Lernfortschritt in GUI und Terminal.

- Frühe Backend-Abbrüche erhalten eine Fehlerdatei; GUI und Terminal zeigen Ursache und Dateipfad. Netzwerkfreigaben beim GUI-Start bleiben erhalten.

- GUI und TUI können mit `bip=IPADRESSE` ein Netzwerkbackend auf Port 5069 nutzen, ohne ein eigenes Backend zu starten. Kein API-Token und keine Bestätigung nötig. Der normale lokale Start bleibt erhalten.

#### GUI, TUI und Weboberfläche / GUI, TUI and Web Interface

- Update notices display formatted release notes without internal comments. Updates download to the Darts-Hub host and install there after confirmation, preserving settings and the installation directory.

- Saved changes automatically appear in other open frontends of the same installation. Unsaved input is preserved; pending updates are indicated and loaded afterwards.

- New guided introduction in German and English: setup, soundpacks, events, HubX and support with dimmed surroundings, animated control highlights, small hands-on tasks that advance automatically, styled additional information and saved learning progress in GUI and terminal.

- Early backend failures produce a failure log; GUI and terminal show the cause and file path. GUI startup preserves network listener settings.

- GUI and TUI can use a network backend on port 5069 with `bip=IPADDRESS`, without starting their own backend. No API token or confirmation is needed. Normal local startup remains available.
