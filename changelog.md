### Deutsch

#### Allgemein / General

- Importierte Userskripte können in GUI und TUI entfernt werden. Der gespeicherte Client-Zugang bleibt erhalten.

- Die Python-Vorlage funktioniert auch direkt als importiertes Userskript ohne erneute Zugangsdaten.

- Gespeicherte Client-ID, Secret-Status und importiertes Userskript sind nach dem Neustart wieder sichtbar.

- Userskripte lassen sich im Dashboard ein- und ausschalten. Eine eigene Live-Konsole zeigt Ausgaben und Fehler in GUI und TUI.

- Der Menüpunkt heißt jetzt User Erweiterung. Eine englisch kommentierte Python-Vorlage zeigt empfangene Spielnachrichten an.

- Eigene Skripte lassen sich nach Prüfung von Client-ID und Secret importieren und automatisch starten. Die neue Schnittstelle liefert gefilterte Spielereignisse.

### English

#### Allgemein / General

- Imported user scripts can be removed in GUI and TUI while keeping the saved client credentials.

- The Python template also works as an imported user script without entering credentials again.

- Saved client ID, secret status and imported user script remain visible after restarting.

- Toggle user scripts from the dashboard. A dedicated live console shows output and errors in GUI and TUI.

- The menu is now named User Extension. An English-commented Python template prints received game messages.

- Import and automatically start scripts after verifying client ID and secret. The new interface provides filtered game events.

#### AwtrixNG

- List, upload and delete GIFs and icons for each device and preview them on an animated LED matrix. Select installed controller icons in event rules.

- New Cricket/Tactics triggers for counting hits, closed fields, points and revealed Hidden-Cricket fields, also in the terminal.

- Combination effects respond to corrected throws.

- Player change only fires for a different player. “Throw or turn change” also detects new visits by the same player; Takeout is available as a separate trigger. Existing combined rules are migrated.
