# GIF

## Deutsch

Für Spielereignisse zuerst das Board unter **Autodarts** verbinden. Der Caller darf ausgeschaltet sein.

1. **GIF → Medien** öffnen, einen Ordner mit GIF-, PNG- oder JPEG-Dateien wählen und speichern.
2. Unter **Ereignisse** die Erweiterung aktivieren und eine Regel anlegen: Auslöser, optional Punktzahl/Spieler, dann Bildquelle wählen.
3. Lokale Datei, direkte öffentliche HTTPS-Bildadresse oder Online-Suche verwenden. Liefert die Suche kein Bild, eine Datei oder direkte Adresse wählen.
4. Dauer einstellen: **0** zeigt das Bild bis zum Entfernen der Darts; sonst gilt die Anzahl Sekunden. Mehrere Bilder sind Zufallsalternativen, keine Abfolge.
5. Unter **Anzeige** Anwendungsfenster, Browser oder beides wählen. **Headless benötigt den Browsermodus.**
6. **Testen**, anschließend **Speichern**. Tests speichern nicht. **Bild ausblenden** beendet die Anzeige sofort.

Im Browser schaltet Doppelklick auf Vollbild. Bei Netzwerkfreigabe die angezeigte Adresse mit Zugangsschlüssel verwenden und vertraulich behandeln.

TUI: Seite **GIF**, **Enter** zum Bearbeiten. Headless nutzt die gespeicherten Einstellungen; [Startargumente](START_ARGUMENTS.md).

## English

Connect your board under **Autodarts** for game events. Caller may stay disabled.

1. Open **GIF → Media**, select a folder containing GIF, PNG or JPEG files and save.
2. Under **Events**, enable the extension and add a rule: trigger, optional score/player filter, then image source.
3. Choose a local file, direct public HTTPS image URL or online search. If search returns no image, use a file or direct URL.
4. Set duration: **0** shows the image until darts are removed; otherwise the value is seconds. Multiple images are random alternatives, not a sequence.
5. Under **Display**, choose application window, browser or both. **Headless requires browser mode.**
6. **Test**, then **Save**. Tests do not save settings. **Dismiss image** clears the display immediately.

Double-click the browser display for fullscreen. For network access, use the displayed URL with its access key and keep it private.

TUI: **GIF**, **Enter** to edit. Headless uses saved settings; [startup arguments](START_ARGUMENTS.md).
