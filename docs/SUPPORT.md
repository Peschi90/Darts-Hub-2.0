# Support / Support

## Deutsch

### Anfrage vorbereiten
1. **Support** im Seitenmenü der GUI oder in der TUI-Navigation öffnen.
2. Kontaktdaten, Betreff und Problembeschreibung eintragen; Zeitraum und betroffene Module wählen.
3. Optionale Windows-Sicherheitsdaten und Benutzeridentität bewusst auswählen.
   **Benutzeridentität ist standardmäßig aus.**
4. Hinweise lesen, zustimmen und **Diagnose sammeln** wählen.
5. **ZIP zur Prüfung speichern** und den Inhalt vor dem Senden prüfen; nach Änderungen neu sammeln.
6. **Supportanfrage senden** wählen und die Anfrage-ID aufbewahren.

### Datenschutz und Probleme
- Das ZIP enthält Logs, Einstellungen und Systemdaten. Zugangsdaten werden geschwärzt,
  aber selbst eingegebene Texte können erhalten bleiben: **Das ZIP ist nicht garantiert anonym.**
- **Der Netzwerk-Geschwindigkeitstest nutzt Cloudflare; der Anbieter sieht die Verbindungs-IP,**
  auch wenn der Bericht keine IP-Adresse enthält.
- Support-Zustimmung und [Telemetrieentscheidung](TELEMETRY.md) sind getrennt.
  Dieselbe dauerhafte Installations-ID ermöglicht die Zuordnung freiwilliger Supportfälle zur Telemetrie.
- Ohne Uploadmöglichkeit funktionieren Sammlung und lokaler ZIP-Export weiterhin.
- ZIP zu groß? Kürzeren Zeitraum oder weniger Module wählen.
- **Sendestatus unbekannt? Nicht blind erneut senden:** Der Server könnte die Anfrage bereits gespeichert haben.

## English

### Prepare a request
1. Open **Support** from the GUI sidebar or TUI navigation.
2. Enter contact details, subject and a problem description; select the period and affected modules.
3. Carefully select optional Windows security data and user identity.
   **User identity is off by default.**
4. Read the notice, give consent and select **Collect diagnostics**.
5. **Save ZIP for review** and inspect its contents before sending; collect again after changes.
6. Select **Send support request** and keep the request ID.

### Privacy and problems
- The ZIP contains logs, settings and system data. Credentials are redacted,
  but user-entered text may remain: **The ZIP is not guaranteed to be anonymous.**
- **The network speed test uses Cloudflare; the provider sees your connection IP,**
  even though the report contains no IP address.
- Support consent is separate from the [telemetry decision](TELEMETRY.md).
  The same persistent installation ID allows voluntary support cases to be linked to telemetry.
- If upload is unavailable, collection and local ZIP export still work.
- ZIP too large? Select a shorter period or fewer modules.
- **Unknown send status? Do not blindly retry:** The server may already have saved the request.
